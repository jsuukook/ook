# 📅 팀원 모니터링 일정 관리 대시보드 (Team Monitoring Scheduler)

> 팀원들의 교대 근무 및 시스템 모니터링 일정을 한눈에 조망하고 관리할 수 있는 모던 경량 웹 애플리케이션입니다.  
> 별도의 복잡한 설치나 백엔드 서버 없이 브라우저에서 즉시 실행되며, 데이터는 안전하게 로컬에 자동 보관됩니다.

---

## 🌟 프로젝트 개요

IT 서비스 운영, 인프라 관제, 개발팀 당직/온콜(On-call) 등에서 팀원별 모니터링 일정을 체계적으로 공유하고 관리할 수 있도록 제작되었습니다.

- **무설치 & 제로 종속성(Zero Dependency)**: 외부 라이브러리 설치 없이 HTML/CSS/JavaScript 표준 기술로 구동
- **직관적인 비주얼**: 팀원별 고유 테마 컬러를 통한 시각적 일정 파악
- **데이터 안정성**: 브라우저 로컬 저장소(`localStorage`) 기반 자동 영구 보존 및 JSON 데이터 백업/복원 지원

---

## ✨ 핵심 기능

### 1. 📅 스마트 캘린더 뷰 (월간 & 주간 전환)
- **월간 뷰 (Month View)**: 한 달 전체의 교대 흐름과 공백일을 한눈에 파악할 수 있는 그리드 뷰
- **주간 뷰 (Week View)**: 주간 단위로 더 넓은 영역에서 상세 업무 및 특이사항을 카드 형태로 확인
- **헤더 내비게이션**: 이전/다음 이동, [오늘] 바로가기, 현재 연월 실시간 표시

### 2. 👥 팀원 관리 & 컬러 코딩 시스템
- 팀원 추가, 직책/역할(인프라, 백엔드, 플랫폼 등) 등록 및 삭제
- 팀원별 **10종 프리셋 테마 컬러** 지정으로 달력 내 뱃지 시각화
- 상단 **팀원 필터 칩(Filter Chips)** 클릭 시 특정 팀원의 일정만 즉시 하이라이트

### 3. ⏰ 모니터링 근무 유형 세분화
- **근무 유형 선택**:
  - `종일 모니터링`: 하루 전체 관제
  - `주간 (09:00 - 18:00)`: 일과 시간 집중 모니터링
  - `오전 (09:00 - 13:00)` / `오후 (13:00 - 18:00)`: 교대 근무
  - `야간 / 당직 (18:00 - 익일 09:00)`: 야간 장애 대응 및 당직
  - `비상 대기 (On-Call)`: 긴급 핫라인 및 1차 연락망
- **업무 메모 작성**: 주요 배포 대응, 점검 내용 등 인수인계 사항 기록

### 4. 🔔 오늘의 당번 실시간 알림 바
- 상단 요약 카드에 **오늘 날짜의 모니터링 담당자**를 자동으로 감지하여 표시
- 당번 태그를 클릭하여 즉시 세부 내용 확인 가능

### 5. 💾 데이터 관리 및 백업/복원
- **자동 저장**: 모든 변경 사항(일정 추가/수정/삭제, 팀원 변경)은 브라우저에 자동 반영
- **JSON 내보내기/가져오기**: 백업 파일(`.json`)을 다운로드하여 다른 PC나 팀원과 공유 가능
- **샘플 데이터 복구 / 전체 초기화**: 빠른 테스트를 위한 예시 데이터 탑재

## 🚀 빠른 시작 가이드 (Quick Start)

### 1. 로컬 환경에서 실행하기
1. 본 저장소를 클론(Clone)하거나 다운로드합니다:
   ```bash
   git clone https://github.com/jsuukook/ook.git
   cd ook
   ```
2. 폴더 내의 **`index.html`** 파일을 더블 클릭하여 웹 브라우저(Chrome, Edge 등)에서 바로 실행합니다.

## 🛠️ 기술 스택 (Tech Stack)

| 구분 | 기술 | 설명 |
| :--- | :--- | :--- |
| **Frontend** | Vanilla JavaScript (ES6+) | 프레임워크 없는 가볍고 빠른 동작 |
| **Markup & Style** | HTML5, CSS3 | Flexbox, CSS Grid, CSS Variables 활용 반응형 UI |
| **Typography** | Pretendard, Noto Sans KR | 현대적이고 가독성 높은 시스템 폰트 |
| **Storage** | Web Storage API (`localStorage`) | 브라우저 내 안전한 데이터 영구 보관 |
| **VCS** | Git, GitHub | 버전 관리 및 협업 |
