# 📅 팀원 모니터링 일정 관리 대시보드 (Web App)

팀원들의 교대 근무 및 모니터링 일정을 한눈에 파악하고 직관적으로 관리할 수 있는 모던 웹 애플리케이션입니다.

---

## 🚀 바로 실행하는 방법

별도의 서버 설치나 복잡한 명령어 없이 **브라우저에서 바로 실행**할 수 있습니다.

1. 탐색기에서 현재 폴더(`바이브코딩`)를 엽니다.
2. **`index.html`** 파일을 더블 클릭하여 Chrome, Edge, Safari 등 브라우저로 실행합니다.
   - 또는 브라우저 창으로 `index.html` 파일을 드래그 앤 드롭하셔도 됩니다.

---

## ✨ 주요 기능 및 특징

### 1. 한눈에 보는 월간 & 주간 캘린더 뷰
- **월간 뷰 (Month View)**: 한 달 전체 일정과 날짜별 담당 팀원을 색상 뱃지로 파악
- **주간 뷰 (Week View)**: 주 단위로 더 상세한 메모 및 업무 내용을 카드 형태로 확인
- **간편 전환**: 상단 토글 버튼을 통해 월간/주간 뷰를 1초 만에 전환

### 2. 팀원 관리 및 고유 테마 컬러
- 우측 상단 **[팀원 관리]** 버튼을 통해 팀원 추가/삭제
- 팀원별로 고유 색상(블루, 에메랄드, 퍼플, 앰버, 핑크 등)을 부여하여 달력에서 시각적으로 즉시 식별 가능
- 역할/직책(인프라, 백엔드, 플랫폼 등) 메모 지원

### 3. 직관적인 모니터링 일정 배정
- 달력의 특정 날짜 또는 `+` 버튼을 누르면 즉시 일정 등록 창 오픈
- 근무 유형 선택: **종일 모니터링, 주간(09~18시), 오전(09~13시), 오후(13~18시), 야간/당직(18~익일09시), 비상 대기(On-Call)**
- 특이사항 및 인수인계 메모 입력 가능

### 4. 오늘의 모니터링 당번 알림 & 팀원별 필터링
- 상단 배너에서 **오늘 날짜의 모니터링 담당자**를 자동으로 감지하여 표시
- 상단 **팀원 필터 칩**을 클릭하면 해당 팀원의 일정만 쏙 골라서 확인 가능

### 5. 안전한 브라우저 로컬 저장소 및 백업/복원
- 브라우저를 닫거나 새로고침해도 데이터가 그대로 유지됩니다 (`localStorage`).
- 우측 상단 설정 아이콘(⚙️)을 통해 **JSON 파일로 내보내기/불러오기**가 가능하여 다른 팀원이나 PC로 쉽게 데이터를 공유할 수 있습니다.

## 📁 파일 구조

```text

├── index.html     # 웹 애플리케이션 메인 HTML 구조
├── style.css      # 모던 UI/UX 반응형 스타일시트
├── app.js         # 캘린더 연산, 팀원/일정 관리, 스토리지 로직
└── README.md      # 사용 안내 문서
```
