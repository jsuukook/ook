# 📅 팀원 모니터링 일정 관리 대시보드 (Team Monitoring Scheduler)

> 팀원들의 교대 근무 및 시스템 모니터링 일정을 한눈에 조망하고 관리할 수 있는 모던 경량 웹 애플리케이션입니다.  
> **Supabase 클라우드 데이터베이스**와 연동하여 모든 팀원이 실시간으로 동일한 일정 데이터를 공유할 수 있으며, 설정 전에는 브라우저 로컬 저장소(`localStorage`)로 무설치 즉시 사용 가능합니다.

---

## 🌟 프로젝트 개요

IT 서비스 운영, 인프라 관제, 개발팀 당직/온콜(On-call) 등에서 팀원별 모니터링 일정을 체계적으로 공유하고 관리할 수 있도록 제작되었습니다.

- **Supabase 클라우드 DB 연동 지원**: 팀 전체가 어디서나 동일한 일정과 팀원 정보를 실시간 공유
- **하이브리드 동작**: Supabase 미설정 시에도 브라우저 로컬 저장소로 100% 정상 작동
- **무설치 & 제로 빌드**: 번들러나 빌드 과정 없이 정적 웹 호스팅(GitHub Pages, Vercel, Netlify 등)이나 로컬에서 바로 실행
- **직관적인 비주얼**: 팀원별 고유 테마 컬러 코딩 및 실시간 당번 알림 바

---

## ✨ 핵심 기능

### 1. 📅 스마트 캘린더 뷰 (월간 & 주간 전환)
- **월간 뷰 (Month View)**: 한 달 전체의 교대 흐름과 공백일을 한눈에 파악할 수 있는 그리드 뷰
- **주간 뷰 (Week View)**: 주간 단위로 더 넓은 영역에서 상세 업무 및 특이사항을 카드 형태로 확인
- **헤더 내비게이션**: 이전/다음 이동, [오늘] 바로가기, 현재 연월 실시간 표시

### 2. ⚡ Supabase 클라우드 데이터베이스 연동
- 상단 **[Supabase 연동]** 버튼 또는 상태 뱃지(`🟢 Supabase 연결됨` / `⚡ 로컬 모드`)를 통해 간편하게 연결
- 웹 화면에서 **Project URL**과 **anon/public Key**만 입력하면 1초 만에 클라우드 DB로 전환
- 기존 로컬 데이터가 있는 경우 Supabase로 **자동 데이터 마이그레이션(업로드)** 지원

### 3. 👥 팀원 관리 & 컬러 코딩 시스템
- 팀원 추가, 직책/역할(인프라, 백엔드, 플랫폼 등) 등록 및 삭제
- 팀원별 **10종 프리셋 테마 컬러** 지정으로 달력 내 뱃지 시각화
- 상단 **팀원 필터 칩(Filter Chips)** 클릭 시 특정 팀원의 일정만 즉시 하이라이트

### 4. ⏰ 모니터링 근무 유형 세분화
- **근무 유형 선택**:
  - `종일 모니터링`: 하루 전체 관제
  - `주간 (09:00 - 18:00)`: 일과 시간 집중 모니터링
  - `오전 (09:00 - 13:00)` / `오후 (13:00 - 18:00)`: 교대 근무
  - `야간 / 당직 (18:00 - 익일 09:00)`: 야간 장애 대응 및 당직
  - `비상 대기 (On-Call)`: 긴급 핫라인 및 1차 연락망
- **업무 메모 작성**: 주요 배포 대응, 점검 내용 등 인수인계 사항 기록

### 5. 🔔 오늘의 당번 실시간 알림 바
- 상단 요약 카드에 **오늘 날짜의 모니터링 담당자**를 자동으로 감지하여 표시
- 당번 태그를 클릭하여 즉시 세부 내용 확인 가능

## 🚀 Supabase 연동 방법 (3단계)

### 1단계: Supabase 프로젝트 생성
1. [Supabase 공식 홈페이지](https://supabase.com)에 로그인하고 새 프로젝트를 생성합니다.

### 2단계: 테이블 스키마 생성
1. Supabase 대시보드 좌측 메뉴에서 **SQL Editor**로 이동합니다.
2. 프로젝트 폴더의 **`schema.sql`** 파일 내용을 복사하여 붙여넣고 **Run** 버튼을 실행합니다.
   *(웹 화면의 [Supabase 연동] 창에서 `📋 SQL 복사하기` 버튼을 누르셔도 바로 복사됩니다)*

### 3단계: API 키 연결
1. Supabase 대시보드 **Project Settings > API** 로 이동합니다.
2. **Project URL**과 **anon / public Key**를 복사합니다.
3. 웹앱 화면 우측 상단의 **[Supabase 연동]** 버튼을 누르고 두 값을 입력한 뒤 **[설정 저장 및 연동]**을 누르면 완료!  
   *(또는 `supabase-config.js` 파일에 직접 입력하셔도 됩니다)*


## 🛠️ 기술 스택 (Tech Stack)

| 구분 | 기술 | 설명 |
| :--- | :--- | :--- |
| **Database** | [Supabase](https://supabase.com) (PostgreSQL) | 서버리스 클라우드 DB, Realtime 동기화 |
| **Frontend** | Vanilla JavaScript (ES6+ async/await) | 가볍고 빠른 비동기 데이터 통신 |
| **Markup & Style** | HTML5, CSS3 | Flexbox, CSS Grid, CSS 변수 테마 |
| **Typography** | Pretendard, Noto Sans KR | 세련된 시스템 폰트 |
| **Fallback Storage** | Web Storage API (`localStorage`) | 오프라인 및 미연동 시 자동 로컬 보관 |
